An [agent skill](https://github.com/margelo/react-native-tgfx/tree/main/.claude/skills/rn-tgfx)
for animation slots, the SkSL subset, camera frames and Skia migration.

## Install

```bash
npx skills add margelo/react-native-tgfx
```

Pick it, or list what is offered:

```bash
npx skills add margelo/react-native-tgfx --skill rn-tgfx
```

```bash
npx skills add margelo/react-native-tgfx --list
```

Or copy the folder into `.claude/skills/` by hand.

## Contents

One reference per task, from drawing to troubleshooting. Its SkSL is checked
against the transpiler:

```bash
bun .claude/skills/rn-tgfx/scripts/check-shaders.ts
```
