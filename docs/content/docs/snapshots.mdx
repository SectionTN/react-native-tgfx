## Snapshot a live canvas

```tsx
const canvas = useRef<CanvasHandle>(null)

async function exportCanvas() {
  if (canvas.current == null) return
  const shot = await canvas.current.snapshot()   // Snapshot
  await canvas.current.save('/absolute/path/out.png')
}
```

[`snapshot`](/api/interfaces/CanvasHandle) returns a [`Snapshot`](/api/interfaces/Snapshot):
PNG/JPEG/WebP bytes, or straight-alpha RGBA8888 rows for `format: 'raw'`, in an
`ArrayBuffer` rather than base64. iOS wraps the native result without a copy;
Android copies the temporary JNI buffer into a Nitro-owned `ArrayBuffer` once.
`save` encodes and writes natively, so the bytes never enter JS.

[`SnapshotOptions`](/api/interfaces/SnapshotOptions) · [`SnapshotFormat`](/api/type-aliases/SnapshotFormat)

### Colour

An encoded readback carries the surface's colour profile, so a
`colorSpace="display-p3"` canvas produces a P3-tagged PNG rather than P3 numbers
labelled sRGB. `scale` goes through a second surface and now carries the space
with it — before, a scaled readback lost the profile a scale-1 one kept.

## Offscreen

[`renderToImage`](/api/functions/renderToImage) renders elements with no canvas
mounted ([`RenderToImageOptions`](/api/interfaces/RenderToImageOptions)).

```tsx
const image = await renderToImage(
  <Rect x={0} y={0} width={512} height={512}>
    <LinearGradient start={{ x: 0, y: 0 }} end={{ x: 512, y: 512 }} colors={['#f0f', '#0ff']} />
  </Rect>,
  { width: 512, height: 512 }
)
```

`colorSpace` picks the offscreen surface's space, exactly as the prop does for
a `<Canvas>`, and the result carries it:

```tsx
const wide = await renderToImage(<Chart data={data} />, {
  width: 512,
  height: 512,
  colorSpace: 'display-p3',
})
```

Match it to the canvas the image is headed for. The tag is what makes drawing it
later a *conversion* rather than a reinterpretation — an untagged image is taken
for whatever space it lands in, so a P3 render dropped on an sRGB canvas would
keep its numbers and change its colours.

[`useOffscreenImage`](/api/functions/useOffscreenImage) is the hook form, re-run
on a dependency change:

```tsx
const badge = useOffscreenImage(<Badge count={n} />, { width: 64, height: 64 }, [n])
```

await renderToPdf(
