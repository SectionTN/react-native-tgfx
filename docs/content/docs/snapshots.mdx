## Snapshot a live canvas

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const canvas = useRef<CanvasHandle>(null)

async function exportCanvas() {
  if (canvas.current == null) return
  const shot = await canvas.current.snapshot()   // Snapshot
  await canvas.current.save('/absolute/path/out.png')
}
```

</Tab>
<Tab value="Imperative">

```ts
// No view: a retained surface renders the same scene and reads it back.
const surface = createOffscreenSurface({ width: 1024, height: 1024 })
scene.attach(surface)

async function exportScene() {
  await surface.save('/absolute/path/out.png')
  // or: const img = await surface.toImage(); await img.save(path)
}
```

</Tab>
</Tabs>

[`snapshot`](/api/interfaces/CanvasHandle) returns a [`Snapshot`](/api/interfaces/Snapshot):
PNG/JPEG/WebP bytes, or straight-alpha RGBA8888 rows for `format: 'raw'`, in an
`ArrayBuffer`. `save` writes the file natively.

[`SnapshotOptions`](/api/interfaces/SnapshotOptions) · [`SnapshotFormat`](/api/type-aliases/SnapshotFormat)

### Colour

Encoded snapshots keep the canvas colour profile, also when scaled.

## Offscreen

[`renderToImage`](/api/functions/renderToImage) renders without a canvas
([`RenderToImageOptions`](/api/interfaces/RenderToImageOptions)). Like
`renderToSvg` and `renderToPdf`, it takes JSX, a `SceneNode[]` or a
[`Scene`](/api/classes/Scene):

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const image = await renderToImage(
  <Rect x={0} y={0} width={512} height={512}>
    <LinearGradient start={{ x: 0, y: 0 }} end={{ x: 512, y: 512 }} colors={['#f0f', '#0ff']} />
  </Rect>,
  { width: 512, height: 512 }
)
```

</Tab>
<Tab value="Imperative">

```ts
const image = await renderToImage(
  [
    rect({ x: 0, y: 0, width: 512, height: 512 }, [
      linearGradient({ start: { x: 0, y: 0 }, end: { x: 512, y: 512 }, colors: ['#f0f', '#0ff'] }),
    ]),
  ],
  { width: 512, height: 512 }
)

// Or a retained Scene - live handle writes are baked at their current values,
// so mutate-and-export loops re-render without rebuilding the tree:
counter.set({ text: `Day ${n}` })
const still = await renderToImage(scene, { width: 400, height: 400 })
```

</Tab>
</Tabs>

`renderToPdf` pages can mix `element` and `scene`.

## Retained surface

[`createOffscreenSurface`](/api/functions/createOffscreenSurface) keeps a GPU
surface and its program alive between renders:

```ts
const surface = createOffscreenSurface({ width: 1024, height: 1024 })
scene.attach(surface)                 // a surface is a scene target, like a view

for (let f = 0; f < 120; f++) {
  t.set({ x: f * 4 })                 // slot write - no re-encode
  surface.flush()                     // render on the offscreen worker
  if (f % 30 === 0) await surface.save(`${dir}/frame-${f}.png`)
}
const still = await surface.toImage() // readback only when asked
surface.dispose()                     // GPU memory is explicit-lifetime
```

`setViewport([zoom, x, y])` crops and zooms the export. `hitTest(x, y, precise)`
works headless. The colour space is fixed at creation. For a single export,
`renderToImage` is cheaper.

`colorSpace` picks the output space, as on a `<Canvas>`:

```tsx
const wide = await renderToImage(<Chart data={data} />, {
  width: 512,
  height: 512,
  colorSpace: 'display-p3',
})
```

Match it to the canvas the image will be drawn on.

[`useOffscreenImage`](/api/functions/useOffscreenImage) is the hook form:

```tsx
const badge = useOffscreenImage(<Badge count={n} />, { width: 64, height: 64 }, [n])
```
