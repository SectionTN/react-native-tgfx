[`useNode`](/api/functions/useNode) returns a [`NodeHandle`](/api/interfaces/NodeHandle).
`set()` changes a mounted node without a React render. Slot-backed writes patch
in place and can run in a worklet; a prop without a slot re-encodes the scene on
the JS thread. Most non-geometry slot families are created lazily, so their
first write re-encodes once and later writes patch in place.

```tsx
import { Canvas, RoundedRect, useNode } from 'react-native-tgfx'

function Box() {
  const box = useNode()

  return (
    <>
      <Canvas style={{ width: 300, height: 200 }}>
        <RoundedRect ref={box} x={20} y={20} width={70} height={50} r={12} color="#4F8EF7" />
      </Canvas>
      <Button title="move" onPress={() => box.set({ x: 120 })} />
    </>
  )
}
```

## Colour from a worklet

```tsx
box.set({ color: '#4F8EF7' })         // JS thread only — the parser lives there
box.set({ color: 0xff4f8ef7 })        // packed AARRGGBB, worklet-safe
box.set({ color: [0.3, 0.5, 1, 1] })  // r, g, b, a in 0..1, worklet-safe
```

## Gestures

```tsx
const pan = Gesture.Pan().onUpdate((e) => {
  'worklet'
  dot.set({ cx: e.x, cy: e.y })
})
```

## What has slots

Geometry, group transform operands, paint values and enums, image handles and
source rectangles, shader uniforms, gradient geometry and stops, blur and
shadow parameters, text and path strings, and `visible`. A handle keeps at most
16 gradient stops, so a longer imperative stop list is truncated. Its uniform
pool holds 32 floats; uniforms that do not fit fall back to re-encoding.

```tsx
fx.set({ uniforms: { uFace: [face.x, face.y], uRadius: face.width / 2 } })
label.set({ text: String(Math.round(fps.value)) })
sprite.set({ rect: { x: frame * 32, y: 0, width: 32, height: 32 } })
fade.set({ end: { x: drag.x, y: 0 }, positions: [0, t] })
glow.set({ blur: 4 + press.value * 12, dy: 2 + press.value * 6 })
```

## Pools

[`createHandle`](/api/functions/createHandle) is `useNode` without the hook, for
making N handles at once. `visible={false}` skips drawing and hit testing.

```tsx
const [dots] = useState(() => Array.from({ length: 64 }, () => createHandle()))

<Canvas>
  {dots.map((ref, i) => (
    <Circle key={i} ref={ref} cx={0} cy={0} r={4} visible={false} color="#fff" />
  ))}
</Canvas>

dots[next].set({ visible: true, cx: x, cy: y })
```

## Buffers

[`useSpriteBuffer`](/api/functions/useSpriteBuffer) and
[`useVertexBuffer`](/api/functions/useVertexBuffer) share a typed array with the
renderer for counts too large for one handle each
([`SpriteBuffer`](/api/interfaces/SpriteBuffer), [`VertexBuffer`](/api/interfaces/VertexBuffer)).

```tsx
const sprites = useSpriteBuffer(512)   // SPRITE_FLOATS per sprite
const count = useSharedValue(0)

<Atlas image={sheet} buffer={sprites} count={count} />

// per frame, in a worklet: srcX, srcY, srcW, srcH, scale, centreX, centreY
sprites.set(i, 0, 0, 16, 16, p.scale, p.x, p.y)
count.value = alive                    // set the count after filling entries
```

`useVertexBuffer` takes a [`VertexBufferOptions`](/api/interfaces/VertexBufferOptions)
(`maxVertices`, optional `maxIndices`, and `textures`/`colors` to reserve those
sections). Its `positions`/`textures`/`colors`/`indices` are plain
`Float32Array` views, written directly from JS:

```tsx
const mesh = useVertexBuffer({ maxVertices: 4, maxIndices: 6 })
mesh.positions.set([0, 0, 200, 0, 0, 200, 200, 200])
mesh.indices.set([0, 1, 2, 1, 2, 3])

<Vertices buffer={mesh} vertexCount={4} indexCount={6} />
```

A worklet's captured `mesh.positions` is a cloned copy, not the shared memory —
call [`meshViews`](/api/functions/meshViews) there to map this runtime's own
view onto the same buffer:

```tsx
const drag = Gesture.Pan().onUpdate((e) => {
  'worklet'
  meshViews(mesh).positions[0] = e.x
})
```
