## Animate slots, not the tree

A `SharedValue` prop or a slot-backed
[`NodeHandle.set`](/api/interfaces/NodeHandle) patches native slot data on the UI
thread. Changing ordinary JSX props through React recompiles and uploads the
scene. An unslotted handle write also recompiles, but skips the React and Fabric
commits.

## Keep children primitive

The reconciler recognises the exported drawings directly. A wrapper function
component falls back to the slower path.

```tsx
{/* fast */}
<Canvas>{shapes.map((s) => <Rect key={s.id} {...s} />)}</Canvas>

{/* falls back */}
<Canvas>{shapes.map((s) => <Star key={s.id} {...s} />)}</Canvas>
```

## Other levers

- `<Group picture>` records a static subtree once; dynamic children fall back
  to direct drawing.
- `<Group layer>` costs an offscreen surface — use it only for group opacity or
  group filters.
- Pool handles with [`createHandle`](/api/functions/createHandle) and toggle
  `visible` instead of mounting and unmounting.
- For large sprite or mesh collections, move to
  [`useSpriteBuffer`](/api/functions/useSpriteBuffer) or
  [`useVertexBuffer`](/api/functions/useVertexBuffer).
- One animated opacity per chain — see [Animation](/docs/animation).

## Measure

With the repository's benchmark app installed and an Android device configured:

```bash
node benchmarks/renderer-benchmark/scripts/run-quick.mjs \
  --tag=mine --renderers=tgfx,thor-gpu,skia-graphite
```
