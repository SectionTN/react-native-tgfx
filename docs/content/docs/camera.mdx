```bash
npm install react-native-vision-camera react-native-vision-camera-worklets
```

[`useCameraFrame`](/api/functions/useCameraFrame) turns a VisionCamera frame into
a [`TgfxImage`](/api/interfaces/TgfxImage) plus a
[`CameraFramePosture`](/api/interfaces/CameraFramePosture) — together a
[`CameraFrameSource`](/api/interfaces/CameraFrameSource). Frames are typed
structurally ([`FrameLike`](/api/interfaces/FrameLike)), so the core package does
not depend on VisionCamera.

```tsx title="Preview.tsx"
import { useCamera, useFrameOutput } from 'react-native-vision-camera'
import { Canvas, CameraFrame, useCameraFrame } from 'react-native-tgfx'

export function Preview() {
  const { image, posture, onFrame } = useCameraFrame()

  const frameOutput = useFrameOutput({
    pixelFormat: 'yuv',
    dropFramesWhileBusy: true,
    enablePhysicalBufferRotation: true,
    onFrame,
  })

  useCamera({
    isActive: true,
    device: 'back',
    outputs: [frameOutput],
  })

  return (
    <Canvas style={StyleSheet.absoluteFill} opaque={true}>
      <CameraFrame image={image} {...posture} />
    </Canvas>
  )
}
```

The snippet assumes camera permission has already been granted; the example
app's face-blur screen uses VisionCamera's `useCameraPermission` before
mounting it.

The camera is a headless frame source driven by `useCamera` — no camera view is
mounted; every visible pixel is drawn by tgfx.

## Zero copy

The frame's platform buffer — `AHardwareBuffer*` on Android, `CVPixelBufferRef`
on iOS, wrapped as a [`NativeBufferLike`](/api/interfaces/NativeBufferLike) —
is imported straight to a texture. No decode, no pixel copy, no
promise: [`imageFromNativeBuffer`](/api/functions/imageFromNativeBuffer) is
synchronous, and YUV planes are converted in the fragment shader rather than on
the CPU. Such a handle is not charged against the decoded-pixel budget; the
memory belongs to whoever produced the buffer.

The first frame creates the handle. Every later frame imports the new native
buffer and replaces the registry entry behind the same handle — no React
render, reconciler commit or program recompile:

```ts
handle.value == null
  ? imageFromNativeBuffer(buffer.pointer, format)   // first frame
  : handle.value.setNativeBuffer(buffer.pointer, format)  // every frame after
```

[`setNativeBuffer`](/api/interfaces/TgfxImage) retains the new buffer and drops
the previous one before returning, so a producer recycling a fixed pool gets its
slot back on the swap.

<Callout type="warn">
The buffer's *contents* must stay unchanged while a handle points at it — tgfx
samples it directly. Write into a pool slot only after it has been swapped out.
</Callout>

`useCameraFrame` owns that lifetime for you: the raw pointer never leaves its
worklet, and a `try`/`finally` releases the buffer and disposes the frame on
every path including a throw.

<Callout type="warn">
The frame passed to your own per-frame callback dies when it returns. Do not
retain it, do not call `getNativeBuffer()` on it again — that is a second retain
nothing releases, and one unreleased buffer stalls the producer's bounded pool —
and never store `getNativeBuffer().pointer`. A stale pointer does not throw; it
imports whatever memory now sits at that address.
</Callout>

## No JS per frame

```bash
npm install react-native-tgfx-vision-camera
```

`useTgfxCameraSink` can move the same zero-copy import into a native
frame-processor plugin so, after attachment completes, no frame reaches a JS
runtime. Attach it once the hook's worklet has minted the handle:

```tsx
const sink = useTgfxCameraSink()

useEffect(() => {
  if (image != null) sink.attach(frameOutput, image.handle)
}, [sink, frameOutput, image])
```

`attach` is asynchronous. The worklet keeps receiving frames until the native
callback is installed; after that, orientation state no longer reaches JS, so
keep `enablePhysicalBufferRotation: true` or stay on `useCameraFrame` alone when
orientation must continue to track.

Not usable when the frame processor has JS work of its own — a per-frame
detector, for instance.

## Shading a frame

```tsx
<CameraFrame image={image} {...posture}>
  <Fill>
    <Shader source={NEON}>
      <ImageShader image={image} />
    </Shader>
  </Fill>
</CameraFrame>
```

<Callout type="warn">
Leave tile modes at `'clamp'`. A YUV frame sampled with any other one comes back
transparent.
</Callout>

## Face blur

The scene compiles once, so allocate a fixed number of slots. An unused slot has
zero size and draws nothing.

```tsx
const SLOTS = [0, 1, 2, 3]
const [ovals] = useState(() => SLOTS.map(() => createHandle()))

const detect = useCallback((frame: Frame) => {
  'worklet'
  const faces = detector.detectFaces(frame)
  for (const i of SLOTS) {
    const b = faces[i]?.bounds
    ovals[i]!.set({
      x: b?.x ?? 0,
      y: b?.y ?? 0,
      width: b?.width ?? 0,
      height: b?.height ?? 0,
    })
  }
}, [detector, ovals])

return { ...useCameraFrame(detect), ovals }
```

```tsx
<CameraFrame image={image} {...posture}>
  {SLOTS.map((i) => (
    <Oval key={i} ref={ovals[i]} x={0} y={0} width={0} height={0}>
      <Paint>
        <ImageShader image={image} />
        <Blur blur={25} />
      </Paint>
    </Oval>
  ))}
</CameraFrame>
```
