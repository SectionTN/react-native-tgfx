## Fonts

The `fonts` prop on [`Canvas`](/api/interfaces/CanvasProps) handles the whole
thing — registration, waiting, and gating — so text never flashes in the
platform fallback and nothing needs a hook:

```tsx
<Canvas
  fonts={{
    "PT Serif": [
      require("./PT_Serif-Web-Regular.ttf"),
      require("./PT_Serif-Web-Bold.ttf"),
    ],
  }}
>
  <Text fontFamily="PT Serif" x={16} y={40} text="ready when you see me" />
</Canvas>
```

The canvas withholds its children until every face is in; a failed load warns
and renders anyway, since fallback text beats a canvas that stays blank
forever. Registration is process-wide and permanent, so a second canvas naming
the same families mounts instantly.

The lower-level pieces remain for readiness in your own UI, or loading outside
React: [`useFonts`](/api/functions/useFonts) registers and returns readiness,
[`loadFont`](/api/functions/loadFont) and [`loadFonts`](/api/functions/loadFonts)
are the callable forms, and
[`registeredFontFamilies`](/api/functions/registeredFontFamilies) queries the
registered family names.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const ready = useFonts({
  "PT Serif": [
    require("./PT_Serif-Web-Regular.ttf"),
    require("./PT_Serif-Web-Bold.ttf"),
  ],
});
```

</Tab>
<Tab value="Imperative">

```ts
await loadFonts({
  "PT Serif": [
    require("./PT_Serif-Web-Regular.ttf"),
    require("./PT_Serif-Web-Bold.ttf"),
  ],
});
```

</Tab>
</Tabs>

Each entry is a [`FontSource`](/api/type-aliases/FontSource) — a `require()`'d
asset, a URI, or raw base64 bytes. `useFonts` stays `false` forever on a
failed load; reach for [`useFontsState`](/api/functions/useFontsState) instead
when that failure needs to be visible rather than just gating the text off:

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const { ready, error } = useFontsState({
  "PT Serif": [require("./PT_Serif-Web-Regular.ttf")],
});
```

</Tab>
<Tab value="Imperative">

```ts
try {
  await loadFonts({ "PT Serif": [require("./PT_Serif-Web-Regular.ttf")] });
} catch (error) {
  // a failed load rejects here
}
```

</Tab>
</Tabs>

## Measurement

[`measureText`](/api/functions/measureText) returns [`TextMeasurement`](/api/interfaces/TextMeasurement) with per-line [`LineMeasurement`](/api/interfaces/LineMeasurement).

```tsx
const box = measureText("measured", { fontSize: 22, fontFamily: "PT Serif" });
const { lines } = measureText(label, { fontSize: 18, width: 200 });
```

## Bidi and complex scripts

Text is shaped through HarfBuzz and reordered by the Unicode bidirectional
algorithm, so Arabic joins into its initial, medial and final forms, Indic
scripts reorder, ligatures and mark positioning apply, and a right-to-left run
reads right to left inside a left-to-right paragraph.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Text x={0} y={40} text="مرحبا بالعالم" fontSize={24} fontFamily="Noto Naskh Arabic" />
<Text x={0} y={80} text="ab مرحبا cd" fontSize={24} fontFamily="Noto Naskh Arabic" />
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  text({
    x: 0,
    y: 40,
    text: "مرحبا بالعالم",
    fontSize: 24,
    fontFamily: "Noto Naskh Arabic",
  }),
);
scene.add(
  text({
    x: 0,
    y: 80,
    text: "ab مرحبا cd",
    fontSize: 24,
    fontFamily: "Noto Naskh Arabic",
  }),
);
```

</Tab>
</Tabs>

The paragraph's base direction comes from its first strong character, so a
string that starts in Arabic lays out right-to-left and one that starts in Latin
does not. `textAlign` is unaffected — it still defaults to `'left'`, so a
right-to-left paragraph that should sit against the right edge needs
`textAlign="right"`.

**A script still needs a face that covers it.** The fallback chain is emoji-only
by design, so register one for anything outside the primary family:

```tsx
await loadFonts({
  "Noto Naskh Arabic": [require("./NotoNaskhArabic-Regular.ttf")],
});
```

Without it the glyphs are `.notdef` — laid out in the right order, drawn as
blanks — and a warning names the codepoint once.

`U+200E`, `U+200F` and `U+061C` — the left-to-right, right-to-left and Arabic
letter marks — work, so a neutral that resolves the wrong way can be placed by
hand.

Three parts of UAX#9 are not implemented. The explicit embedding, override and
isolate controls (`U+202A`–`U+202E`, `U+2066`–`U+2069`) are treated as
formatting characters with no direction of their own. The paired-bracket rule N0
is absent, so a bracket takes its direction from its surroundings rather than
from its pair. And P1 is not applied: a `<Text>` is one paragraph however many
newlines it holds, so every line shares the base direction the first strong
character set. W1–W7, N1–N2, I1–I2 and L1–L2 are all there, with format
characters removed as X9 requires.

## Hit testing

[`glyphPositionAtCoordinate`](/api/functions/glyphPositionAtCoordinate) turns a
point into an insertion point, and
[`rectsForRange`](/api/functions/rectsForRange) turns a byte range into the
boxes it occupies — a caret and a selection, from the same layout `<Text>` draws.

Both take the coordinates `measureText` reports, with the first baseline at
`y = 0`, so subtract the `x`/`y` you gave `<Text>` from the touch point first.

```tsx
const style = { fontSize: 17, fontFamily: "PT Serif", width: 320 };

const at = glyphPositionAtCoordinate(text, style, touch.x - x, touch.y - y);
// at.index is a UTF-8 byte offset; at.leading says which half of the glyph it
// landed on, and at.line which line it resolved to after clamping.

const boxes = rectsForRange(text, style, selection.start, selection.end);
// One box per line the range crosses; a one-glyph range is that glyph's bounds.
```

`index` is always the insertion point, never a glyph to advance past. `leading`
says which half produced it — the leading half of the glyph starting there, or
the trailing half of the one ending there — which is the affinity a caret needs
at a wrap, where one offset has two positions on screen.

**Not every offset has a box.** The space a line wraps at, a newline, and the
ellipsis a truncated line ends with all draw nothing, so a caret drawn from the
glyph at `index` needs the one before it as a fallback:

```tsx
const at = rectsForRange(text, style, caret, caret + 1)[0];
const before =
  at == null ? rectsForRange(text, style, caret - 1, caret)[0] : undefined;
const x = at ? at.x : before ? before.x + before.width : 0;
const rule = at ?? before;
```

Each call lays the paragraph out, the same as
[`measureText`](/api/functions/measureText) — cheap for a tap, wasteful once a
frame. [`TextBox`](/api/interfaces/TextBox) is what `rectsForRange` returns.

Offsets are UTF-8 byte offsets throughout, matching `startIndex` on
[`LineMeasurement`](/api/interfaces/LineMeasurement) — for ASCII they are the
same as JS string indices, and for anything else they are not. `TextBox.endIndex`
is exclusive, where `LineMeasurement.endIndex` names its last glyph.

## Text as a path

[`textToPath`](/api/functions/textToPath) returns SVG path data, so text can be
stroked, clipped or path-operated like any other shape.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const outline = textToPath('outlined', { fontSize: 44, fontFamily: 'PT Serif' })

<Group transform={[{ translateX: 8 }, { translateY: 60 }]}>
  <Path path={outline} color="#d98a4a" style="stroke" strokeWidth={2} />
</Group>
```

</Tab>
<Tab value="Imperative">

```ts
const outline = textToPath("outlined", {
  fontSize: 44,
  fontFamily: "PT Serif",
});

scene.add(
  group({ transform: [{ translateX: 8 }, { translateY: 60 }] }, [
    path({ path: outline, color: "#d98a4a", style: "stroke", strokeWidth: 2 }),
  ]),
);
```

</Tab>
</Tabs>

[`TextPath`](/api/variables/TextPath) lays text along a path instead.

## Glyphs

[`glyphIds`](/api/functions/glyphIds) plus [`Glyphs`](/api/variables/Glyphs) place
each glyph yourself ([`PlacedGlyph`](/api/interfaces/PlacedGlyph)).

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const style = { fontSize: 32, fontFamily: 'PT Serif' }
const ids = glyphIds('wave', style)

<Glyphs
  x={20}
  y={60}
  {...style}
  glyphs={ids.map((id, i) => ({ id, x: i * 22, y: Math.sin(i) * 8 }))}
/>
```

</Tab>
<Tab value="Imperative">

```ts
const style = { fontSize: 32, fontFamily: "PT Serif" };
const ids = glyphIds("wave", style);

scene.add(
  glyphs({
    x: 20,
    y: 60,
    ...style,
    glyphs: ids.map((id, i) => ({ id, x: i * 22, y: Math.sin(i) * 8 })),
  }),
);
```

</Tab>
