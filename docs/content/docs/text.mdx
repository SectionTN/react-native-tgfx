## Fonts

The `fonts` prop on [`Canvas`](/api/interfaces/CanvasProps) loads fonts before
the children render:

```tsx
<Canvas
  fonts={{
    "PT Serif": [
      require("./PT_Serif-Web-Regular.ttf"),
      require("./PT_Serif-Web-Bold.ttf"),
    ],
  }}
>
  <Text fontFamily="PT Serif" x={16} y={40} text="ready when you see me" />
</Canvas>
```

A failed load warns and renders anyway.

[`useFonts`](/api/functions/useFonts) returns readiness.
[`loadFont`](/api/functions/loadFont) and [`loadFonts`](/api/functions/loadFonts)
work outside React.
[`registeredFontFamilies`](/api/functions/registeredFontFamilies) lists
registered families.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const ready = useFonts({
  "PT Serif": [
    require("./PT_Serif-Web-Regular.ttf"),
    require("./PT_Serif-Web-Bold.ttf"),
  ],
});
```

</Tab>
<Tab value="Imperative">

```ts
await loadFonts({
  "PT Serif": [
    require("./PT_Serif-Web-Regular.ttf"),
    require("./PT_Serif-Web-Bold.ttf"),
  ],
});
```

</Tab>
</Tabs>

Each entry is a [`FontSource`](/api/type-aliases/FontSource). Use
[`useFontsState`](/api/functions/useFontsState) to see load errors:

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const { ready, error } = useFontsState({
  "PT Serif": [require("./PT_Serif-Web-Regular.ttf")],
});
```

</Tab>
<Tab value="Imperative">

```ts
try {
  await loadFonts({ "PT Serif": [require("./PT_Serif-Web-Regular.ttf")] });
} catch (error) {
  // a failed load rejects here
}
```

</Tab>
</Tabs>

## Measurement

[`measureText`](/api/functions/measureText) returns [`TextMeasurement`](/api/interfaces/TextMeasurement) with per-line [`LineMeasurement`](/api/interfaces/LineMeasurement).

```tsx
const box = measureText("measured", { fontSize: 22, fontFamily: "PT Serif" });
const { lines } = measureText(label, { fontSize: 18, width: 200 });
```

## Bidi and complex scripts

Complex scripts and mixed-direction text are shaped and reordered.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Text x={0} y={40} text="مرحبا بالعالم" fontSize={24} fontFamily="Noto Naskh Arabic" />
<Text x={0} y={80} text="ab مرحبا cd" fontSize={24} fontFamily="Noto Naskh Arabic" />
```

</Tab>
<Tab value="Imperative">

```ts
scene.add(
  text({
    x: 0,
    y: 40,
    text: "مرحبا بالعالم",
    fontSize: 24,
    fontFamily: "Noto Naskh Arabic",
  }),
);
scene.add(
  text({
    x: 0,
    y: 80,
    text: "ab مرحبا cd",
    fontSize: 24,
    fontFamily: "Noto Naskh Arabic",
  }),
);
```

</Tab>
</Tabs>

The first strong character sets the direction. Right-to-left text still needs
`textAlign="right"`.

**A script still needs a face that covers it:**

```tsx
await loadFonts({
  "Noto Naskh Arabic": [require("./NotoNaskhArabic-Regular.ttf")],
});
```

Otherwise glyphs draw blank, with a warning.

Direction marks `U+200E`, `U+200F` and `U+061C` work. Embedding, override and
isolate controls, bracket pairing (N0) and per-line direction (P1) do not.

## Hit testing

[`glyphPositionAtCoordinate`](/api/functions/glyphPositionAtCoordinate) maps a
point to an insertion point.
[`rectsForRange`](/api/functions/rectsForRange) maps a byte range to boxes.
Subtract the `<Text>` `x`/`y` from the touch point first.

```tsx
const style = { fontSize: 17, fontFamily: "PT Serif", width: 320 };

const at = glyphPositionAtCoordinate(text, style, touch.x - x, touch.y - y);
// at.index is a UTF-8 byte offset; at.leading says which half of the glyph it
// landed on, and at.line which line it resolved to after clamping.

const boxes = rectsForRange(text, style, selection.start, selection.end);
// One box per line the range crosses; a one-glyph range is that glyph's bounds.
```

**Not every offset has a box.** Fall back to the glyph before it:

```tsx
const at = rectsForRange(text, style, caret, caret + 1)[0];
const before =
  at == null ? rectsForRange(text, style, caret - 1, caret)[0] : undefined;
const x = at ? at.x : before ? before.x + before.width : 0;
const rule = at ?? before;
```

Each call runs layout, like [`measureText`](/api/functions/measureText), so
avoid it every frame. `rectsForRange` returns [`TextBox`](/api/interfaces/TextBox).

Offsets are UTF-8 bytes, like `startIndex` on
[`LineMeasurement`](/api/interfaces/LineMeasurement). They match JS string
indices only for ASCII. `TextBox.endIndex` is exclusive.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
{
  boxes.map((box, i) => (
    <Rect
      key={i}
      x={box.x}
      y={box.y}
      width={box.width}
      height={box.height}
      color="#cfe4ff"
    />
  ));
}
```

</Tab>
<Tab value="Imperative">

```ts
for (const box of boxes) {
  scene.add(
    rect({
      x: box.x,
      y: box.y,
      width: box.width,
      height: box.height,
      color: "#cfe4ff",
    }),
  );
}
```

</Tab>
</Tabs>

## Text as a path

[`textToPath`](/api/functions/textToPath) returns text as SVG path data.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const outline = textToPath('outlined', { fontSize: 44, fontFamily: 'PT Serif' })

<Group transform={[{ translateX: 8 }, { translateY: 60 }]}>
  <Path path={outline} color="#d98a4a" style="stroke" strokeWidth={2} />
</Group>
```

</Tab>
<Tab value="Imperative">

```ts
const outline = textToPath("outlined", {
  fontSize: 44,
  fontFamily: "PT Serif",
});

scene.add(
  group({ transform: [{ translateX: 8 }, { translateY: 60 }] }, [
    path({ path: outline, color: "#d98a4a", style: "stroke", strokeWidth: 2 }),
  ]),
);
```

</Tab>
</Tabs>

[`TextPath`](/api/variables/TextPath) lays text along a path.

## Glyphs

[`glyphIds`](/api/functions/glyphIds) plus [`Glyphs`](/api/variables/Glyphs) place
each glyph yourself ([`PlacedGlyph`](/api/interfaces/PlacedGlyph)).

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const style = { fontSize: 32, fontFamily: 'PT Serif' }
const ids = glyphIds('wave', style)

<Glyphs
  x={20}
  y={60}
  {...style}
  glyphs={ids.map((id, i) => ({ id, x: i * 22, y: Math.sin(i) * 8 }))}
/>
```

</Tab>
<Tab value="Imperative">

```ts
const style = { fontSize: 32, fontFamily: "PT Serif" };
const ids = glyphIds("wave", style);

scene.add(
  glyphs({
    x: 20,
    y: 60,
    ...style,
    glyphs: ids.map((id, i) => ({ id, x: i * 22, y: Math.sin(i) * 8 })),
  }),
);
```

</Tab>
</Tabs>
