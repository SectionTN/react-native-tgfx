Paint effects and shaders are children of a drawing or
[`Paint`](/api/variables/Paint). A `Paint` child on a
[`Group`](/api/variables/Group) supplies inherited paint defaults. Masks and
backdrops are drawing nodes; dash and corner effects are children of `Path`.

## Blend modes

`blendMode` on any drawing or [`Paint`](/api/variables/Paint) ([`BlendMode`](/api/type-aliases/BlendMode)).

```tsx
<Circle cx={80} cy={70} r={45} color="#f2c088" />
<Circle cx={120} cy={70} r={45} color="#6aa9ff" blendMode="multiply" />
```

## Colour filters

```tsx
<Image image={photo} x={0} y={0} width={200} height={200} fit="cover">
  <ColorMatrix matrix={GREYSCALE} />
</Image>
```

[`ColorMatrix`](/api/variables/ColorMatrix) (4×5, row-major) ·
[`BlendColor`](/api/variables/BlendColor) ·
[`Luma`](/api/variables/Luma) ·
[`AlphaThreshold`](/api/variables/AlphaThreshold)

```tsx
<Path path="M20 80 L80 20 L140 80 L80 140 Z" color="#ffffff">
  <BlendColor color="#e0533d" mode="src" />
</Path>
```

`<AlphaThreshold>` cuts translucency to a hard edge — alpha below `threshold`
becomes fully transparent, at or above it fully opaque, colours untouched. It is
tgfx's own, with no Skia equivalent, and `threshold` is animatable.

## Filter order

Filters compose in declaration order, and that holds across the two kinds. The
scope is one node's own children: a `<Paint>` child and an inherited group paint
are merged rather than chained, so a colour filter arriving from either of those
stays on the paint and runs first whatever else the node declares.

```tsx
<Luma /><Blur blur={8} />   // luminance, then blur the result
<Blur blur={8} /><Luma />   // blur, then take the luminance of that
```

A colour filter normally runs on the paint, before anything is rasterised, so on
its own it can never follow a blur. Declared after one it joins the image chain
instead, which is what makes the second line above mean what it reads like.
Declared first it stays on the paint, which is cheaper: a paint colour filter
costs no offscreen.

The composition this exists for is blurring an alpha and then cutting it back to
a solid shape — a sticker outline, a metaball:

```tsx
<Circle cx={100} cy={100} r={40} color="#6aa9ff">
  <Blur blur={12} />
  <AlphaThreshold threshold={0.6} />
</Circle>
```

## Gradients and noise

[`LinearGradient`](/api/variables/LinearGradient) ·
[`RadialGradient`](/api/variables/RadialGradient) ·
[`SweepGradient`](/api/variables/SweepGradient) ·
[`DiamondGradient`](/api/variables/DiamondGradient) ·
[`ColorShader`](/api/variables/ColorShader) ·
[`FractalNoise`](/api/variables/FractalNoise) ·
[`Turbulence`](/api/variables/Turbulence)

```tsx
<Rect x={0} y={0} width={300} height={140}>
  <LinearGradient
    start={{ x: 0, y: 0 }}
    end={{ x: 300, y: 0 }}
    colors={['#d98a4a', '#6aa9ff']}
  />
</Rect>
```

[`Blend`](/api/variables/Blend) folds its shader children from left to right:

```tsx
<Rect x={0} y={0} width={256} height={256}>
  <Blend mode="multiply">
    <RadialGradient center={{ x: 128, y: 128 }} r={128} colors={['blue', 'yellow']} />
    <Turbulence freqX={0.05} freqY={0.05} octaves={4} />
  </Blend>
</Rect>
```

## Film grain

[`FilmGrain`](/api/variables/FilmGrain) is a child of a
[`Group`](/api/variables/Group), not a paint: it dusts tgfx's `NoiseStyle` over
what the group actually drew, clipped to that alpha rather than to a bounding
box.

```tsx
<Group>
  <Image image={photo} x={0} y={0} width={300} height={200} />
  <FilmGrain size={2} density={0.4} color="rgba(255,255,255,0.35)" />
</Group>
```

`color` alone gives single-colour grain, its alpha the grain's opacity. Adding
`secondColor` splits the grain into two complementary halves, one per colour —
the classic light-and-dark stock look. Naming neither keeps the noise's own RGB
and takes its strength from `opacity`.

```tsx
<FilmGrain size={3} density={0.5} color="white" secondColor="black" />
<FilmGrain size={1.5} density={0.6} opacity={0.25} />
```

`size`, `density`, `seed` and the colour channels are value slots, so grain
animates without a commit — a per-frame `seed` is what makes it crawl like film
rather than sit still:

```tsx
const seed = useSharedValue(0)
useFrameCallback(() => { seed.value += 1 })

<FilmGrain size={2} density={0.4} color="white" seed={seed} />
```

`opacity` is written only in the colourless mode, and `blendMode` moves through
a handle rather than a shared value — an enum reaches a slot as its wire code,
which only `set()` resolves. `secondColor` re-encodes through a handle; passing
it as `[r, g, b, a]` with shared values in it keeps it live.

A grained group is drawn once and then replayed into an offscreen for the style,
so it costs about two draws of its subtree per frame. Keep the grained subtree
to what needs the grain rather than wrapping the whole scene, and note that a
`<Group picture>` holding one is never recorded — a recording has no surface to
measure the grain against.

## Backdrop

[`BackdropBlur`](/api/variables/BackdropBlur) and [`Glass`](/api/variables/Glass)
read the pixels already drawn beneath them.

```tsx
<Image image={photo} x={0} y={0} width={300} height={200} />
<BackdropBlur x={20} y={40} width={260} height={120} r={24} blur={16} />
<Glass x={20} y={40} width={260} height={120} r={24} refraction={40} frost={30} />
```

The panel is sampled, not painted, so of the inherited paint only `opacity`,
`visible` and `ref` apply, plus the alpha of `color`. It has no hit bounds, so
it is never pressable, and it reads the surface — put it *after* the content it
frosts, and note that a `<Group picture>` holding one is never recorded.

### Lighting the glass

`refraction`, `depth`, `frost` and `dispersion` shape the material; `splay`,
`lightAngle` and `lightIntensity` light it. Together they are the whole of
tgfx's `GlassStyle`.

```tsx
<Glass
  x={20} y={40} width={260} height={120} r={24}
  refraction={40} depth={20} frost={30}
  splay={0}            // 0 follows the edge curvature, 100 aims at the centre
  lightAngle={45}      // degrees; 0 is straight above, positive turns clockwise
  lightIntensity={50}  // 0 removes the highlight and leaves refraction and frost
/>
```

The defaults are the values the renderer used to hardcode, so a `<Glass>` that
names none of them looks exactly as it did. `lightIntensity` defaults to 50
rather than tgfx's own 80, which over most content reads as chrome rather than
as glass.

Every one of those eight — `blur` included — is a value slot, so the whole
material animates without a commit:

```tsx
const angle = useSharedValue(45)
const panel = useNode()

<Glass ref={panel} x={20} y={40} width={260} height={120} r={24} lightAngle={angle} />
// or, from an event handler: panel.set({ lightAngle: 120 })
```

Only `r` is static — it is a clip, not a material parameter.
