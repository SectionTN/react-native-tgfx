Paths are SVG path strings. Every helper accepts one; helpers that create or
modify geometry return another SVG path string.

```tsx
import { Path, pathOp } from 'react-native-tgfx'

const plate = 'M0 0 L120 0 L120 120 L0 120 Z'
const hole = 'M40 40 L80 40 L80 80 L40 80 Z'

<Path path={pathOp(plate, hole, 'difference')} color="#4F8EF7" />
```

| Function | Returns |
| --- | --- |
| [`pathOp`](/api/functions/pathOp) | path produced by union / difference / intersect / xor ([`PathOp`](/api/type-aliases/PathOp)) |
| [`pathBounds`](/api/functions/pathBounds) | [`PathBounds`](/api/interfaces/PathBounds) |
| [`pathContains`](/api/functions/pathContains) | `boolean` |
| [`pathTransform`](/api/functions/pathTransform) | path, by [`PathMatrix`](/api/type-aliases/PathMatrix) |
| [`pathLength`](/api/functions/pathLength) | `number` |
| [`pathPointAtLength`](/api/functions/pathPointAtLength) | [`PathPoint`](/api/interfaces/PathPoint) with `angle` in radians |
| [`pathSegment`](/api/functions/pathSegment) | sub-path between two distances |

## Along a path

```tsx
const route = 'M8 170 q90 -70 170 0 t160 -6'
const at = pathPointAtLength(route, pathLength(route) * progress)

<Group transform={[{ translateX: at.x }, { translateY: at.y }, { rotate: at.angle }]}>
  <Path path={arrow} color="#FF3B30" />
</Group>
```

## Trim and dash

`start` and `end` on [`PathProps`](/api/interfaces/PathProps) trim the path to
normalised fractions of its length.
[`DashPathEffect`](/api/variables/DashPathEffect) and
[`CornerPathEffect`](/api/variables/CornerPathEffect) are path-effect children.

```tsx
<Path path={route} style="stroke" strokeWidth={4} end={progress}>
  <DashPathEffect intervals={[10, 5]} phase={march} />
</Path>
```
