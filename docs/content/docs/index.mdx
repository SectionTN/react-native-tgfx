---

```tsx
import { Canvas, Circle, Rect } from 'react-native-tgfx'

export default function App() {
  return (
    <Canvas style={{ width: 300, height: 140 }}>
      <Rect x={0} y={0} width={300} height={140} color="#101725" />
      <Circle cx={70} cy={70} r={44} color="#d98a4a" />
    </Canvas>
  )
}
```

Each scene commit compiles the drawing structure to a binary buffer. Between
commits, animated values live in slots that the native renderer patches on the
UI thread, so they need no JavaScript work per frame.

- Shapes, paths, [text](/docs/text), [images](/docs/images), atlases, meshes
- [Paint](/api/variables/Paint) as a component, inherited through [`Group`](/api/variables/Group)
- Gradients, noise, colour matrices, blurs, shadows, masks
- Runtime [shaders](/docs/shaders) with UI-thread uniforms
- [Camera frames](/docs/camera), [snapshots, PDF and SVG export](/docs/snapshots)
- [Headless scenes](/docs/headless) with no React — built on the JS thread or [inside a worklet](/docs/headless#worklets)
- [Vulkan](/docs/installation#rendering-backend-android) by default on Android (OpenGL ES one flag away), Metal on iOS
- [Prewarm at launch](/docs/performance#prewarm-at-launch): `Tgfx.prewarm()` in `Application.onCreate`, or a `TgfxPrewarm` key in `Info.plist`, builds the GPU device and font table on a background thread before React Native starts, so the first canvas builds its window in 11.9 ms instead of 28.4 ms

The package version in this source revision is an alpha release.
