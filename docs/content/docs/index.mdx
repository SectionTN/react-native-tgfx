```tsx
import { Canvas, Circle, Rect } from 'react-native-tgfx'

export default function App() {
  return (
    <Canvas style={{ width: 300, height: 140 }}>
      <Rect x={0} y={0} width={300} height={140} color="#101725" />
      <Circle cx={70} cy={70} r={44} color="#d98a4a" />
    </Canvas>
  )
}
```

Animated values update on the UI thread with no JavaScript work per frame.

- Shapes, paths, [text](/docs/text), [images](/docs/images), atlases, meshes
- [Paint](/api/variables/Paint) as a component, inherited through [`Group`](/api/variables/Group)
- Gradients, noise, colour matrices, blurs, shadows, masks
- Runtime [shaders](/docs/shaders) with UI-thread uniforms
- [Camera frames](/docs/camera), [snapshots, PDF and SVG export](/docs/snapshots)
- [Headless scenes](/docs/headless), also [inside a worklet](/docs/headless#worklets)
- [Vulkan](/docs/installation#rendering-backend-android) on Android, Metal on iOS
- [Prewarm at launch](/docs/performance#prewarm-at-launch)

Alpha release.
