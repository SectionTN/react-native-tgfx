## Canvas

The root. Everything else must be a descendant.

```tsx
import { Canvas, Rect } from 'react-native-tgfx'

function Panel() {
  return (
    <Canvas style={{ width: 300, height: 140 }}>
      <Rect x={0} y={0} width={300} height={140} color="#101725" />
    </Canvas>
  )
}
```

| prop | type | default |
| --- | --- | --- |
| `style` | view style | — |
| `composite` | `'layer' \| 'texture'` | `'layer'` |
| `opaque` | `boolean` | `false` |
| `debug` | `boolean` | `false` |

`composite: 'layer'` punches through the window: React Native content *behind*
the canvas does not show through its transparent pixels, and view transforms do
not apply to it. Use `'texture'` when the canvas has to compose with views
behind it or be transformed.

Children draw in document order — later siblings paint over earlier ones.

## Shapes

| component | props |
| --- | --- |
| `Rect` | `x`, `y`, `width`, `height` |
| `RoundedRect` | `x`, `y`, `width`, `height`, `r`, or `rx`/`ry` to override `r` per axis |
| `Oval` | `x`, `y`, `width`, `height` |
| `Circle` | `cx`, `cy`, `r` |
| `Line` | `x1`, `y1`, `x2`, `y2` |
| `Path` | `path` — SVG path data, `string` |
| `Image` | `image`, `x`, `y`, `width`, `height`, `fit`, `sampling`, `rect` |
| `Text` | `text`, `x`, `y`, `fontSize`, `fontFamily` |
| `Fill` | none of its own — covers the canvas |

Every geometric prop above is `Animated<number>`, so it may be a plain number or
a Reanimated `SharedValue`. The exceptions are `path`, `text` and `fontFamily`
(plain `string` — there is no value slot for a string, so a `SharedValue` there
would never animate), `image` (a native handle from `useImage`), and the
`fit`/`sampling`/`rect` enums.

`Text.fontSize` defaults to `14`. All of these take the paint props below.

### Image

`image` is a `TgfxImage` handle from [`useImage`](#useimage) — a small integer on
the wire, never bytes.

`fit` is the full Skia set, default `'contain'`:

| fit | what it does |
| --- | --- |
| `'contain'` | scales down to fit inside the box, letterboxed |
| `'cover'` | fills the box, cropping the source |
| `'fill'` | stretches to the box, ignoring aspect ratio |
| `'fitWidth'` | matches the box width, cropping vertically if needed |
| `'fitHeight'` | matches the box height, cropping horizontally if needed |
| `'none'` | native size, centred |
| `'scaleDown'` | like `'fill'`, but never enlarges |

As in Skia, `cover` crops the *source* rather than overflowing the destination,
so nothing is ever drawn outside the box.

`sampling` is `'nearest' | 'linear' | 'mipmap'`, default `'linear'`. Use
`'mipmap'` when a large image is drawn into a much smaller box — it builds the
mip chain, which `'linear'` alone does not.

`rect` is a source sub-rect in image pixels, so a sprite sheet is drawn without
slicing it in JS:

```tsx
<Image
  x={0} y={0} width={60} height={60}
  image={sheet}
  rect={{ x: 32, y: 0, width: 32, height: 32 }}
  sampling="nearest"
/>
```

### Line ignores `style`

A line has no interior, so it is always stroked. Passing `style="fill"` to
`<Line>` still draws a stroke.

### Fill

`Fill` has no geometry of its own but takes every paint prop and accepts
children, which makes it the natural host for a shader:

```tsx
import { Canvas, Fill, Shader } from 'react-native-tgfx'

const source = `
uniform float2 uSize;
half4 main(float2 pos) {
  float2 uv = pos / uSize;
  return half4(uv.x, uv.y, 0.6, 1.0);
}
`

function Backdrop({ width, height }: { width: number; height: number }) {
  return (
    <Canvas style={{ width, height }}>
      <Fill>
        <Shader source={source} uniforms={{ uSize: [width, height] }} />
      </Fill>
    </Canvas>
  )
}
```

Coverage comes from the device-space clip, so a transform on an enclosing
`Group` moves the paint but not the area filled — as in Skia.

## Paint

Set directly on a shape, or inherited from a `<Paint>` child:

```tsx
import { Circle, Paint } from 'react-native-tgfx'

<Circle cx={70} cy={70} r={40}>
  <Paint color="#f2c088" style="stroke" strokeWidth={3} />
</Circle>
```

| prop | type | default |
| --- | --- | --- |
| `color` | `Animated<Color>` — hex, `rgb()`/`rgba()`, `hsl()`/`hsla()`, or a named colour | black |
| `style` | `'fill' \| 'stroke'` | `'fill'` |
| `strokeWidth` | `Animated<number>` | `1` |
| `strokeCap` | `'butt' \| 'round' \| 'square'` | `'butt'` |
| `strokeJoin` | `'miter' \| 'round' \| 'bevel'` | `'miter'` |
| `opacity` | `Animated<number>` | `1` |
| `antiAlias` | `boolean` | `true` |

A `<Paint>` inside a `<Group>` sets the inherited default for descendants; inside
a shape it overrides that shape only, including its `opacity`.

To stroke *and* fill one shape, draw it twice — one fill, one stroke. That is
what the engine does anyway.

## Group

Applies transforms and inherited paint to its children.

```tsx
import { Group, Rect } from 'react-native-tgfx'

<Group transform={[{ translate: [40, 0] }, { rotate: '12deg' }, { scale: 1.5 }]}>
  <Rect x={0} y={0} width={40} height={40} />
</Group>
```

| prop | type |
| --- | --- |
| `transform` | `Transform[]` |
| `origin` | `Vector` — `{ x, y }`, the point transforms are applied about |

Operations apply in array order. The full set is `translate`, `translateX`,
`translateY`, `scale`, `scaleX`, `scaleY`, `rotate`, `rotateZ`, `skewX`, `skewY`.

Rotations accept a string with a `deg` or `rad` suffix. A bare number is
radians — and an **animated** rotation is always radians, because a `SharedValue`
carries no unit. Convert in your worklet if you are thinking in degrees.

When no operand is animated the matrix is folded at compile time and costs
nothing per frame. One animated operand moves the whole group onto the per-frame
path — worth knowing when a static group sits inside an animated one.

## Gradients and noise

Children of a shape or `<Paint>`. They draw nothing on their own.

| component | props |
| --- | --- |
| `LinearGradient` | `start`, `end`, `colors`, `positions` |
| `RadialGradient` | `center` (or `cx`/`cy`), `r`, `colors`, `positions` |
| `SweepGradient` | `c` (or `center`, or `cx`/`cy`), `start`, `end`, `colors`, `positions` |
| `DiamondGradient` | same props as `RadialGradient` |
| `FractalNoise` | `freqX`, `freqY`, `octaves`, `seed` |
| `Turbulence` | same props as `FractalNoise` |
| `Shader` | `source`, `uniforms` — see [shaders](/docs/shaders) |
| `ImageShader` | `image`, `tx`, `ty`, `sampling`, `rect`, `fit` |

`colors` is `Color[]` and `positions` is `number[]`. `SweepGradient`'s `start`
and `end` are **degrees**, as in Skia, defaulting to a full 0–360 turn. Noise
defaults are `freqX` and `freqY` `0.05`, `octaves` `1`, `seed` `0`.

Gradient geometry (`start`, `end`, `center`, `r`), `positions`, `colors` and all
noise parameters are read once at commit and do not animate.

### ImageShader

An image as the paint source for any shape — textured fills, image-backed masks,
tiled patterns:

```tsx
import { Circle, ImageShader, useImage } from 'react-native-tgfx'

const photo = useImage(require('./cat.png'))

photo != null && (
  <Circle cx={60} cy={60} r={50}>
    <ImageShader image={photo} rect={{ x: 10, y: 10, width: 100, height: 100 }} fit="cover" />
  </Circle>
)
```

`tx` and `ty` are `'clamp' | 'repeat' | 'mirror' | 'decal'`, both defaulting to
`'clamp'` — the tile mode outside the image's own bounds. `sampling` is the same
set as `<Image>`. `rect` is the destination rect the image is mapped into with
`fit`; omit both to sample the image 1:1 in canvas space, which is what tiling
usually wants.

```tsx
import { LinearGradient, Rect } from 'react-native-tgfx'

<Rect x={0} y={0} width={300} height={140}>
  <LinearGradient
    start={{ x: 0, y: 0 }}
    end={{ x: 300, y: 0 }}
    colors={['#d98a4a', '#6aa9ff']}
  />
</Rect>
```

## Hooks

### useImage

```tsx
const image: TgfxImage | null = useImage(require('./cat.png'))
```

Takes `number | string` — a `require()` asset, an `http(s)`, `file:`, `data:`,
`asset:` or `content:` URI, or a raw base64 string. Returns a native image
handle, or `null` until it is ready.

The handle carries `width`, `height` and a `dispose()`. The draw program only
ever carries its integer id, so a scene's string table does not grow with the
image bytes on screen and a re-commit costs no hashing and no decode.

A local file (`file:` URI, or a bundled asset that resolves to a path) is opened
and decoded natively — its bytes never enter JS. A remote or Metro-served URI
still goes through `fetch`, but as an `ArrayBuffer`; nothing is base64-encoded on
the JS thread. Every path decodes on a background thread, so no frame waits on a
decode.

The handle is disposed when the source changes or the component unmounts.

### useImageState

```tsx
const { data, error, loading } = useImageState(source)
```

Returns `ImageState`: `data: TgfxImage | null`, `error: Error | null`,
`loading: boolean`. `data` is cleared the moment `source` changes, so a slow or
failing load never leaves the previous image on screen.

### imageFromNativeBuffer

```tsx
const frameImage = imageFromNativeBuffer(
  frame.getNativeBuffer().pointer,
  'bt601-limited'
)
```

Wraps a platform hardware buffer — an `AHardwareBuffer*` on Android, a
`CVPixelBufferRef` on iOS — as an image handle. Zero-copy and synchronous: the
buffer is imported straight to a GPU texture through
`tgfx::Image::MakeFrom(HardwareBufferRef, YUVColorSpace)`, with no decode and no
CPU round trip.

`format` is `PixelFormat`: `'rgba'` for a single-plane surface, or one of
`'bt601-limited'` (the camera default), `'bt601-full'`, `'bt709-limited'`,
`'bt709-full'`, `'bt2020-limited'`, `'bt2020-full'`, `'jpeg-full'`.

For a stream of frames, keep the handle and call `image.setNativeBuffer(...)` per
frame: the scene keeps referencing the same id, so nothing is re-committed and an
undrawn frame is superseded by the next rather than queued behind it. Such a
handle is not accounted against the decoded-pixel budget — the memory belongs to
whoever produced the buffer.

### setImageCacheLimit

```tsx
setImageCacheLimit(32 * 1024 * 1024)
```

Byte budget for decoded pixel buffers held between draws — a real LRU keyed on
the handle, defaulting to 64 MB. An image the budget drops is re-decoded on next
use, never lost. Decoded GPU textures are bounded separately by the tgfx context
cache limit (192 MB).

### useClock

Returns a `SharedValue<number>` holding **seconds** since the first frame,
written on the UI thread. See [animation](/docs/animation).

## Escape hatch

`TgfxNativeView` is exported for callers who want to drive the native view
directly — pushing a `scene` buffer and a values buffer themselves rather than
going through `<Canvas>`. Its ref type is `TgfxViewRef`. Most code should not
need it.

## Types

The package exports its prop types alongside the components — `CanvasProps`,
`RectProps`, `CircleProps`, `PaintProps`, `GroupProps`, `ShaderProps`,
`ImageState`, `ImageShaderProps`, `TgfxImage`, and the shared `Animated<T>`,
`Color`, `Fit`, `Sampling`, `SrcRect`, `TileMode`, `Vector`, `Transform` and
`TransformOp`. `DiamondGradient` and `Turbulence` reuse `RadialGradientProps` and
`NoiseProps` respectively.

## What is not supported

- No clipping primitive is exposed.
- No blend modes, blurs, or image filters at the component level.
- No `ImageSVG`: SVG documents are not parsed, only single path data strings.
- No child shaders — `uniform shader` is rejected at compile time. See
  [shaders](/docs/shaders).
- Colours, paths, text, images, gradient geometry and noise parameters do not
  animate. See [animation](/docs/animation).
