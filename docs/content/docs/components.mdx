## Canvas

The root. Everything else must be a descendant.

```tsx
<Canvas style={{ width: 300, height: 140 }}>{/* drawings */}</Canvas>
```

`style` is a normal React Native view style. Children draw in document order —
later siblings paint over earlier ones.

## Shapes

| component | props |
| --- | --- |
| `Rect` | `x`, `y`, `width`, `height` |
| `RoundedRect` | `x`, `y`, `width`, `height`, `r` or `rx`/`ry` |
| `Oval` | `x`, `y`, `width`, `height` |
| `Circle` | `cx`, `cy`, `r` |
| `Line` | `x1`, `y1`, `x2`, `y2` |
| `Path` | `path` (SVG path data) |
| `Image` | `image`, `x`, `y`, `width`, `height`, `fit` |
| `Text` | `text`, `x`, `y`, `fontSize`, `fontFamily` |
| `Fill` | none — covers the canvas |

Every numeric prop accepts `Animated<number>` except where
[animation](/docs/animation) says otherwise. All shapes take the paint props below.

### Fill

`Fill` covers the whole canvas without being told its size, which makes it the
natural host for a shader:

```tsx
<Fill>
  <Shader source={src} uniforms={{ uSize: [w, h] }} />
</Fill>
```

Coverage comes from the device-space clip, so a transform on an enclosing
`Group` moves the paint but not the area filled — as in Skia.

## Paint

Set directly on a shape, or inherited from a `<Paint>` child:

```tsx
<Circle cx={70} cy={70} r={40}>
  <Paint color="#f2c088" style="stroke" strokeWidth={3} />
</Circle>
```

| prop | values |
| --- | --- |
| `color` | any CSS colour string |
| `style` | `'fill'` (default) or `'stroke'` |
| `strokeWidth` | number, animatable |
| `strokeCap` | `'butt'`, `'round'`, `'square'` |
| `strokeJoin` | `'miter'`, `'round'`, `'bevel'` |
| `opacity` | number, animatable |
| `antiAlias` | boolean, default `true` |

A `<Paint>` inside a `<Group>` sets the inherited default for descendants; inside
a shape it overrides that shape only.

To stroke *and* fill one shape, draw it twice — one fill, one stroke. That is
what the engine does anyway.

## Group

Applies transforms and inherited paint to its children.

```tsx
<Group transform={[{ translate: [40, 0] }, { rotate: '12deg' }, { scale: 1.5 }]}>
  <Rect x={0} y={0} width={40} height={40} />
</Group>
```

Operations apply in array order: `translate`, `scale`, `rotate`, `skewX`,
`skewY`. Rotations take a string with `deg` or `rad`.

When no operand is animated the matrix is folded at compile time and costs
nothing per frame. One animated operand puts the whole group on the per-frame
path — worth knowing when a static group sits inside an animated one.

## Shaders

Gradient and noise shaders are children of a shape or `<Paint>`:

| component | props |
| --- | --- |
| `LinearGradient` | `start`, `end`, `colors`, `positions` |
| `RadialGradient` | `center`, `r`, `colors`, `positions` |
| `SweepGradient` | `center`, `start`, `end`, `colors` — degrees, as in Skia |
| `DiamondGradient` | `center`, `r`, `colors` |
| `FractalNoise` | `freqX`, `freqY`, `octaves`, `seed` |
| `Turbulence` | same as `FractalNoise`, sharper |
| `Shader` | `source`, `uniforms` — see [shaders](/docs/shaders) |

## Hooks

### useImage

```tsx
const data = useImage(require('./cat.png'))
```

Accepts a `require()` asset, an `http(s)`/`file`/`data`/`asset`/`content` URI, or
a raw base64 string. Returns `null` until the bytes are available.

Use `useImageState` when you need to tell "still loading" from "failed" — it
returns `{ data, error, loading }`, and clears the bytes the moment `source`
changes so a slow or failing load never leaves the previous image on screen.

### useClock

Seconds since the first frame, as a UI-thread `SharedValue`. See
[animation](/docs/animation).

## What is not supported

- No clipping primitive is exposed.
- No blend modes, blurs, or image filters at the component level.
- No child shaders — `uniform shader` is rejected at compile time rather than
  producing invalid GPU code. See [shaders](/docs/shaders).
- Colours and paths do not animate. See [animation](/docs/animation).
