[`Shader`](/api/variables/Shader) runs tgfx's SkSL subset
([`ShaderProps`](/api/interfaces/ShaderProps)). `main` gets local coordinates and
returns premultiplied `half4`.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
import { Canvas, Fill, Shader } from 'react-native-tgfx'

const source = `
uniform float2 uSize;
half4 main(float2 pos) {
  float2 uv = pos / uSize;
  return half4(uv.x, uv.y, 0.6, 1.0);
}
`

<Canvas style={{ width: 300, height: 140 }}>
  <Fill>
    <Shader source={source} uniforms={{ uSize: [300, 140] }} />
  </Fill>
</Canvas>
```

</Tab>
<Tab value="Imperative">

```ts
import { Scene, fill, shader } from 'react-native-tgfx'

const source = `
uniform float2 uSize;
half4 main(float2 pos) {
  float2 uv = pos / uSize;
  return half4(uv.x, uv.y, 0.6, 1.0);
}
`

const scene = Scene.create()
scene.add(
  fill({}, [
    shader({ source, uniforms: { uSize: [300, 140] } }),
  ])
)
```

</Tab>
</Tabs>

<Callout>
Declarations must come before `main()`.
</Callout>

## Animated uniforms

Uniforms accept a `SharedValue`. [`useClock`](/api/functions/useClock) counts
seconds.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const t = useClock()

<Fill>
  <Shader source={source} uniforms={{ uTime: t, uSize: [width, height] }} />
</Fill>
```

</Tab>
<Tab value="Imperative">

```ts
const clock = createClock()

scene.add(
  fill({}, [
    shader({ source, uniforms: { uTime: clock.value, uSize: [width, height] } }),
  ])
)
```

</Tab>
</Tabs>

## Shader inputs

One shader child per `uniform shader`, in order.

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
const source = `
uniform shader img;
uniform float uShift;

half4 main(float2 pos) {
  half4 base = img.eval(pos);
  half4 red = img.eval(pos + float2(uShift, 0.0));
  half4 blue = sample(img, pos - float2(uShift, 0.0));
  return half4(red.r, base.g, blue.b, base.a);
}
`

<Shader source={source} uniforms={{ uShift: 4 }}>
  <ImageShader image={image} fit="cover" rect={{ x: 0, y: 0, width: 300, height: 200 }} />
</Shader>
```

</Tab>
<Tab value="Imperative">

```ts
const source = `
uniform shader img;
uniform float uShift;

half4 main(float2 pos) {
  half4 base = img.eval(pos);
  half4 red = img.eval(pos + float2(uShift, 0.0));
  half4 blue = sample(img, pos - float2(uShift, 0.0));
  return half4(red.r, base.g, blue.b, base.a);
}
`

shader({ source, uniforms: { uShift: 4 } }, [
  imageShader({ image, fit: 'cover', rect: { x: 0, y: 0, width: 300, height: 200 } }),
])
```

</Tab>
</Tabs>

Inputs can be any shader:

<Tabs items={['Declarative', 'Imperative']}>
<Tab value="Declarative">

```tsx
<Shader source={banded}>
  <LinearGradient start={{ x: 0, y: 0 }} end={{ x: 300, y: 0 }} colors={['#2b6cff', '#ff3b6b']} />
</Shader>
```

</Tab>
<Tab value="Imperative">

```ts
shader({ source: banded }, [
  linearGradient({ start: { x: 0, y: 0 }, end: { x: 300, y: 0 }, colors: ['#2b6cff', '#ff3b6b'] }),
])
```

</Tab>
</Tabs>

A count mismatch throws:

```
[tgfx] shader: the source declares 1 'uniform shader' (img) but 0 shader children
were given - pass one shader child per declaration, in order
```
